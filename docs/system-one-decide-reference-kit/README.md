# Справочный комплект: Decision-модели (System One) и инструмент `decide-mcp`

> **Версия комплекта:** v1.1 (2026-11-23).

Этот комплект объединяет официальные спецификации и рекомендации разработчиков decision-моделей (`TypeSafe Jev`, `Google Gemini Decision 1`, `Microsoft-Decision-1 / 1.1`, `OpenAI GPT-6 Luna Decisions`), стандарты API `/v1/systemone` и `/v1/decisions`, а также практический опыт разработки, замеров и боевых пилотов инструмента `decide-mcp`.

Комплект спроектирован модульно: каждый документ самодостаточен и может использоваться как инженером при проектировании новых пайплайнов (код, тексты, логи, агентские сессии, мультимодальные проверки), так и в качестве готового контекста для языковых моделей.

## Быстрая навигация по задачам

- **Нужно срочно зарядить новую нейросеть пониманием темы без долгих объяснений:** возьми один файл `07-llm-bootstrap-brief.md`.
- **Выбираешь модель и считаешь стоимость прогона:** открой `01-models-passport-and-economics.md` и матрицу в `02-primitives-matrix-and-api.md`.
- **Проектируешь новый пайплайн анализа (код, тексты, логи, датасеты, видео/PDF):** иди по шагам `03-universal-analysis-algorithm.md`, подсматривая готовые оси в `04-use-cases-and-rubrics-library.md`.
- **Хочешь добавить визуальную локализацию объектов (`box`) или проверку OCR/скриншотов:** читай раздел про `box` в `02-primitives-matrix-and-api.md`, кейс №6 в `04-use-cases-and-rubrics-library.md` и план доработки в `06-decide-mcp-architecture-and-roadmap.md`.
- **Модель ставит всем карточкам «3 из 3» или валит всё в `other`:** открой `05-pitfalls-and-antipatterns.md` (ловушки №1, №2, №5, №7, №9).

## Главный принцип всего комплекта

> **Модель судит, код вычисляет.**
> Decision-модели (System One) — не замена рассуждающим LLM и не замена детерминированному коду. Они закрывают ровно один зазор: быстро, параллельно и без парсинга свободного текста превращают сырые данные в калиброванные вероятности, поверх которых код маршрутизирует поток, а рассуждающая модель (System Two) работает только с отфильтрованной выжимкой.
